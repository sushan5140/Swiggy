**Subject:** Independent prototype: verifying a shopping assistant's full basket against a user's intent

Hello Builders Club team,

I'm Susan Reddy Panjugula, an independent software and AI developer from Hyderabad. I've been building a small, read-only research prototype exploring a question relevant to AI-assisted grocery shopping: can an explicit intent contract help an agent identify when a proposed basket no longer satisfies the user's requirements?

The local demonstration uses fictional product data and a vegetarian pasta example to illustrate budget changes, unavailable items, missing ingredient labels and unapproved substitutions. It compares intentionally simple local reference checks against an explicit constraint verifier. It does not access Swiggy's systems or claim a problem in Instamart, and the current evaluation is limited to synthetic test cases.
